BATERÍA DE SEGURIDAD DEL FORMULARIO — paso 10, blueprint §5
============================================================

Cómo se corrió
--------------
Servidor de producción (`next build` + `next start`) en un árbol de trabajo
aparte, para no tocar el servidor de desarrollo de otra sesión.

Los tres servicios externos, en la corrida:

  Turnstile  servicio REAL, con las claves de prueba PÚBLICAS que Cloudflare
             documenta: 1x…AA «siempre pasa» y 2x…AA «siempre falla».
  Upstash    doble local que habla el subconjunto REST que usa el endpoint
             (`/pipeline` con INCR + EXPIRE … NX). Es la única forma de
             provocar «excedido» y «servicio caído» sin esperar diez minutos.
  Resend     corridas A/B/D contra la API real con una clave inválida — el
             happy path llega hasta Resend y solo muere ahí, que es la prueba
             de que las seis capas lo dejaron pasar. La corrida C apunta el
             `const RESEND_EMAILS` a un doble local para ver el 200 y, sobre
             todo, QUÉ sale hacia el correo. Ese parche vive solo en el árbol
             de QA y se revirtió; el archivo del repo nunca cambió.

Cada caso usa su propia IP en `X-Forwarded-For` para que el rate limit de uno
no contamine al siguiente.

Lectura del caso 18 (inyección)
-------------------------------
Lo que entró:  nombre «Ana\r\nBcc: victima@ejemplo.mx», negocio
               «<script>alert(1)</script>Taller», mensaje con <b>, con
               «javascript:alert(1)», con tres saltos de línea seguidos y con
               una URL legítima.
Lo que salió:  asunto en UNA sola línea —el \r\n colapsó a espacio, así que no
               hay cabecera nueva que inyectar—, etiquetas fuera, el esquema
               `javascript:` fuera, los tres saltos reducidos a dos, y la URL
               legítima intacta: un prospecto que manda su sitio actual es el
               caso de uso, no el ataque. El correo va sin campo `html`.

Lo que esta batería NO prueba
-----------------------------
- Un envío real por Resend. Hace falta la clave y el dominio verificado.
- El reto visible de Turnstile con una clave real. Con las claves de prueba el
  widget se pinta y emite token, pero no plantea desafío.
